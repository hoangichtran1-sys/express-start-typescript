# ExpressJS + Pnpm + Typescript + PostgreSQL(Neon)/DrizzleORM + Authentication with Session and Google OAuth + Uploadthing(File upload) + Swagger OpenAPI

To install dependencies:

```bash
pnpm install
```

To run:

```bash
pnpm run dev (Development)
pnpm run build + pnpm start (Production)
```

This project was created using `pnpm init`. [Pnpm](https://pnpm.io) is a fast all-in-one JavaScript runtime.
